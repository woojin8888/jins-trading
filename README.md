# Jin's Trading · 진스트레이딩

흰색 배경의 미국·한국 주식 차트 워크스페이스입니다. 이 저장소와 Supabase 프로젝트는 기존 사이트에서 독립되어 있으며 기존 프로젝트의 코드·테이블·로그인 데이터를 변경하지 않습니다.

- 사이트: https://jins-trading.vercel.app
- GitHub: https://github.com/woojin8888/jins-trading

## 기능

- 미국장·한국장 종목 검색, 15분·30분·1시간·4시간·일·주·월 캔들, 확대·이동·크로스헤어, 기간 선택 및 차트 PNG 다운로드
- 양봉 빨강·음봉 파랑, 거래량은 전봉보다 증가 시 빨강·감소 시 파랑 (같음·이전값 없음은 회색)
- 종류·기간·기준 가격·색상·두께를 정하는 이동평균선, 숫자·평균선이 있는 거래량 패널, 14일 Wilder ATR%
- 업로드 Pine 기준 미너비니 8조건·가중 RS, 기존 지수 대비 RS·TOP100 백분위 구분
- J TRADING 워터마크, 티커 표시 체크박스와 브라우저 설정 저장
- 거래량 기본 한글 축약 (만주·억주), 정확한 주수·K/M 선택
- 선택한 비교 지수 대비 RS 선차트, TOP100 유니버스 내 RS 백분위
- 보이는 구간/최근 N봉 매물대 추정, POC·VAH·VAL 및 가치 영역 설정
- 60거래일을 20일씩 나눈 VCP 수축 탐색
- 검색 없이 열리는 미국·한국 종목 목록: 거래대금·시가총액·상승률·하락률·거래량 순, 100개씩 추가 조회
- 한국어 종목명과 코스피·코스닥 코드 연결, 기존 TOP100 RS 스크리너와 조건 필터 유지
- 지지·저항 수평선, 두 점 추세선, 사각형, 원·타원, 화살표, 텍스트 그리기 도구
- 관심종목·관심그룹·종목 메모. 미로그인 시 브라우저 저장, 로그인 시 Supabase 동기화
- 모바일 레이아웃, 키보드 접근 가능한 버튼·모달

## 월 0원 우선 개발 범위

목표는 TradingView 유료 분석 기능을 자체 차트에서 구현하는 독립 서비스입니다. 기능 구현 여부와 시세 데이터의 정확도·범위는 별도로 확인합니다. 기존 호스팅·Supabase 무료 한도 안에서 우선 개발하며, 이번 리플레이·CSV 기능은 브라우저에서 이미 조회한 자료로 처리합니다. 새 유료 API 계약·유료 플랜·유료 데이터 저장소를 추가하지 않았습니다. 무료 서비스 한도를 넘는 사용량까지 비용 0원을 보장하는 의미는 아닙니다.

**운영 방침 (2026-11-20): 증권사 API를 연결하지 않고 추가 월 이용료 0원 범위로 개발합니다.** 나무·키움 등 증권사 API 신청·키 발급을 요구하지 않으며 유료 시세 구독·고정 IP·서버·플랜 업그레이드를 추가하지 않습니다. 현재 차트는 Yahoo Finance, 종목 순위는 TradingView Screener, 한국어 종목명은 Naver 공개 자료를 사용합니다. 공개 자료의 조회 가능 여부가 거래소 공식 데이터 계약이나 무제한 이용 보장을 뜻하지는 않습니다. 무료 제공처의 조회 제한·장애는 기존 자료의 기준 시각과 오류로 알리고 가상 시세로 대체하지 않습니다.

기존 차트·보조지표·관심목록·리플레이·CSV는 유지합니다. 주식·ETF 분석은 정규장 기준을 유지하며 NXT·프리·애프터는 아직 연결하지 않았습니다. 해당 세션의 실제 자료를 무료로 확보하기 전에는 별도 점선 시세도 생성하지 않습니다. 지연 시간은 제공처가 명시한 값만 표시하며 모든 종목이 일괄 15~20분 지연이라고 가정하지 않습니다.

## 과거 봉 리플레이·OHLCV 내보내기

차트 상단 **리플레이**를 누르면 그 시점에 조회한 자료를 고정하고 최근 약 120봉 앞에서 시작합니다. 날짜나 위치 슬라이더로 시작 봉을 고르고 한 봉씩 전진·후진하거나 1/2/5배속으로 재생합니다. 진행 중인 최신 봉과 아직 끝나지 않은 주·월봉은 재생 대상에서 제외합니다. 일·주·월·15분·30분·1시간·4시간 모두 확보한 정규장 자료 범위에서 작동합니다.

캔들·이동평균·RS·매물대·분석 카드에 재생 시점 이후의 봉을 넣지 않습니다. 분봉 리플레이의 ATR·VCP·일봉 거래량 카드는 그 거래일 이전의 확정 일봉만 사용하며 카드에 기준을 표시합니다. 재생 가격의 변화율은 **이전 제공 봉 대비**로 표시해 최신 시세의 전일 등락률과 구분합니다. 현재 시세 목록·실시간 메모·기존 도형·분할 차트를 숨기고 새 도형은 메모리에만 보관합니다. 재생 종료 시 임시 도형은 사라지고 기존 도형·차트 구성을 복원합니다. 기존 서버 알림은 계속 동작하나 재생 화면에서 새 실시간 알림을 만들 수 없습니다.

현재 시세로 복귀하면 즉시 다시 조회합니다. 종목·봉 주기·비교 지수 변경 또는 다른 페이지 이동은 리플레이를 종료합니다. 시작 시 받은 과거 데이터의 사후 수정·분할 반영까지 과거 당시 상태로 복원하는 point-in-time 데이터베이스는 아닙니다. 봉 내부 틱 순서나 체결 가능 가격·전략 성과를 재현하지 않습니다.

**CSV**는 차트의 선택 봉 주기·제공 구간을 내보냅니다. 리플레이 중에는 공개한 봉까지만 내보냅니다. 일봉·주봉·월봉에는 임의의 체결 시각을 생성하지 않고 날짜만 기록합니다. 분봉에는 UTC와 거래소 현지 시각을 함께 기록하며, 거래량 미제공은 빈칸, 실제 0은 0으로 구분합니다. 음수 선물 가격을 보존하고 텍스트의 스프레드시트 수식 실행을 방지합니다. 리플레이 PNG에도 과거 재생 표시를 추가합니다.

## 차트 전체화면

차트 오른쪽 위 **전체화면** 버튼을 누르면 헤더·종목 목록·분석 카드 대신 차트와 조작 도구를 화면 가득 표시합니다. **닫기** 또는 `Esc`로 원래 화면으로 돌아옵니다. 차트 안에 포커스가 있으면 `Alt+Enter`로도 전환할 수 있습니다. 기존 **전체 구간 보기** 버튼은 차트의 기간을 맞추는 기능으로 별도 유지합니다.

브라우저 Fullscreen API를 먼저 사용하고, 지원하지 않거나 요청이 거절되는 환경에서는 앱 화면을 채웁니다. 모바일의 주소 표시줄 숨김은 브라우저 지원에 따릅니다. 차트를 재생성하지 않고 크기를 바꾸므로 이동평균·보조지표·매물대·그리기 상태를 유지합니다. 지표 설정창도 전체화면 안에서 열리며, 설정창이 열려 있으면 `Esc`로 설정창을 먼저 닫습니다. 복귀 시 페이지 스크롤·버튼 포커스를 복원합니다.

## 종목 목록과 차트 그리기

오른쪽 **종목 목록** 탭은 처음부터 열려 있습니다. 정렬을 바꾸면 로드한 100개만 재정렬하지 않고 대상 시장 전체에서 순위를 다시 조회합니다. **다음 100개 더 보기**로 목록을 이어서 보고 종목을 누르면 해당 차트가 열립니다. 미국은 NASDAQ·NYSE·AMEX 개별주식, 한국은 코스피·코스닥 개별주식을 대상으로 하며 ETF·OTC·코넥스는 제외합니다. 기존 스크리너의 RS와 조건 필터는 거래대금 TOP100 기준을 유지합니다.

한국 이름과 시장 구분은 Naver Finance의 공개 종목 자료를 사용합니다. `server/korean-stocks.json`은 2026-11-17 기준 이름·시장 구분만 담으며 가격 데이터는 포함하지 않습니다. `python scripts/update-korean-stocks.py`로 전체 목록을 갱신할 수 있습니다. 새 상장 종목이 순위에 반영되려면 목록을 갱신해 재배포해야 합니다. 새 코드 직접 조회는 별도 한국어 이름 조회를 시도하고 이름 제공처 실패가 가격 차트 조회를 막지 않도록 합니다.

차트 위 그리기 도구에서 **수평선·추세선·사각형·원·타원·화살표·텍스트**를 선택합니다. 수평선·텍스트는 한 번, 나머지는 시작점과 끝점을 차례로 누르면 완성됩니다. 모바일에서도 같은 순서로 두 번 탭합니다. **선택** 모드에서 도형 전체 또는 끝점을 끌어 수정하고 색·1~4px 두께를 바꿉니다. 텍스트는 도구 행의 입력란에서 편집합니다.

- **도형** 목록에서 개별 선택·숨김·삭제, 해당 종목 전체 삭제를 지원합니다.
- `Esc` 취소, `Delete` 삭제, `Ctrl/Cmd+Z` 실행 취소, `Ctrl/Cmd+Shift+Z`·`Ctrl/Cmd+Y` 다시 실행 (차트 또는 그리기 도구에 포커스가 있을 때). 전체 삭제도 실행 취소할 수 있습니다.
- 도형은 화면 픽셀이 아닌 날짜·가격으로 저장해 확대·이동·일/주/월봉 변경에 맞춰 다시 표시하며, 가격 차트 영역에만 그립니다. PNG 다운로드에도 포함됩니다.
- 종목당 최대 200개, 실행 취소 40단계입니다. 로그인하면 계정·시장·종목별로 Supabase에 저장하고 다른 기기에서 복원합니다. 로그인 전에는 브라우저에 저장합니다. 게스트의 도형을 계정에 자동 합치지 않습니다. 실제 체결·주문 기능은 아닙니다.

## 업로드 Pine의 상대강도

기존 시작값 100 지수 대비 RS와 TOP100 백분위는 사용자가 제공한 Pine의 `rs_rating`과 다른 지표였습니다. 이제 기본 RS와 미너비니는 다음 수식을 사용합니다.

`RS = (0.4 × C/C[13] + 0.2 × C/(2C[26]) + 0.2 × C/(3C[39]) + 0.2 × C/(4C[52])) × 100`

13·26·39·52는 개월이 아닌 선택한 주기의 봉 수입니다. 원본의 분모 2·3·4를 그대로 유지하며, 일정한 가격의 RS는 약 61.67입니다. IBD 백분위나 지수 대비 상대수익률이 아니고 0~100 범위로 제한하지 않습니다. 원본의 `RS > 70` 조건도 그대로 사용합니다.

원본 표의 `barstate.islastconfirmedhistory`에 맞춰 RS 카드·조건표·기본 RS 선은 마지막 확정 봉을 기준으로 표시합니다. 진행 중인 봉은 제외하고 평가 시각을 표시합니다. 원본과 동일한 수식이어도 시세 공급처·세션·수정주가·봉 주기·누락 봉·확정 시점이 다르면 TradingView 값과 차이가 날 수 있습니다. TradingView에서 직접 스크립트를 실행한 대조는 도구 제한으로 하지 못했습니다.

**RS 계산 방식**에서 기존 **지수 대비 RS · 시작 100**도 선택할 수 있습니다. 스크리너의 **TOP100 백분위**는 그대로 유지합니다. 업로드된 결합 Pine의 Volume Profile 절은 이번 RS 수정에서 포팅하지 않았고, 기존 추정 매물대를 유지합니다. 포팅 파일과 저작자·라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 기록했습니다.

## 분·시간봉과 워터마크

차트 위 **봉 주기**에서 15분·30분·1시간·4시간을 선택합니다. 15·30분은 제공처의 최근 1개월, 1시간은 최근 최대 2년 자료를 요청합니다. 신규 상장·조회 제한·제공처 누락에 따라 실제 범위는 짧아질 수 있고 화면에 제공 범위를 표시합니다. 정규장 원본 분봉만 사용하며 일봉으로 분봉을 만들어내지 않습니다.

4시간봉은 정규장 시작에 맞춰 실제 1시간봉을 묶습니다. 미국은 09:30·13:30, 한국은 09:00·13:00 시작이며, 마지막 봉은 장 마감에 맞춰 짧아질 수 있습니다. 미국 서머타임·조기 마감은 제공처 세션을 반영합니다. 원본 중간 누락이 있는 집계는 제외합니다. 제공처가 끝에 붙이는 0거래량 시세 스냅샷은 새 봉으로 계산하지 않습니다.

한국 원본에 세션 마감이 15:00으로 표시되는 사례를 확인했습니다 (실제 KRX는 15:30). 이 차이와 제외 봉 수를 화면에 알리고 없는 30분 데이터를 합성하지 않습니다. 이 피드의 분봉을 TradingView와 완전히 같은 세션 데이터라고 보장하지 않습니다. 차트 축은 미국 뉴욕·한국 서울 시간, 시세 제공/조회 시각 안내는 KST입니다. 분봉 조회 실패는 오류로 알리며 일봉을 분봉으로 대체하지 않습니다.

워터마크는 캔들·그리드보다 뒤의 네이티브 배경 레이어에 왼쪽 아래 작은 연한 글씨로 표시합니다. 매물대·그리기 도구보다 앞에 겹치지 않고, PNG에서도 별도로 덧그리지 않습니다. 워터마크는 **J TRADING**이며 **워터마크 티커** 체크박스로 선택 종목 티커를 켜거나 끕니다. 설정은 브라우저에 저장되고 PNG 내보내기에도 반영합니다. 거래량은 기본으로 `1,234.6만주`, `1.23억주`처럼 표시하고, 정확한 주수는 숫자 도움말이나 거래량 설정의 **정확한 주수**에서 확인합니다. 이전 설정을 이관할 때 기존 지표·선 설정은 유지하고 기본 거래량 표시를 한글 축약으로 바꿉니다.

## 차트 조작 · 분할 · 알림 · 조건 검색 · 관심목록

- **차트 조작**: 가격 영역 우클릭 → 클릭 가격의 수평선, 가격 알림, 이동평균 설정, 전체 구간, PNG 저장. 이동평균선 가까이를 더블클릭하면 해당 선의 기간·기준 가격·색·두께를 바로 편집합니다. 모바일은 **차트 메뉴** 버튼을 사용합니다.
- **멀티 차트**: 단일·2분할·4분할을 선택합니다. 보조 차트의 봉 주기를 각각 바꾸고, 종목·십자선·시간축 연동을 따로 켜고 끕니다. 종목 연동을 끄면 각 보조 차트에서 티커를 입력합니다. 동일 종목의 다른 주기, 다른 종목의 비교를 지원합니다. 모바일에서는 세로로 배치합니다. 차트 구성 전체를 전체화면으로 볼 수 있고 기존 배경 워터마크는 유지합니다.
- **계정 저장**: 이동평균·보조지표·거래량·매물대·워터마크 설정, 선택 시장·종목·봉 주기·기간, 차트 배치, 도형, 검색 조건과 관심목록을 계정별로 저장합니다. 새 문서는 해당 계정의 기존 로컬 도형을 이관하고 원본 로컬 데이터는 유지합니다. 기존 공용 차트 설정은 첫 계정에만 귀속시키며 계정 전환 시 다른 계정으로 복사하지 않습니다. 게스트 문서는 계정에 자동 병합하지 않습니다. 원격 복원이 끝나기 전에는 해당 문서를 수정하지 않고, 연속 저장은 순서대로 처리하며 실패 시 재시도합니다. 여러 기기에서 같은 문서를 동시에 수정하면 마지막 저장 값이 적용됩니다. 다른 기기의 변경은 새로 접속할 때 복원합니다.
- **알림**: 로그인 후 가격 이상/이하 도달, 확정 일봉 SMA 상향 돌파, 확정 일봉 거래량/직전 20일 평균 배수, 업로드 RS 기준 알림을 만듭니다. 서버가 약 1분마다 대기 알림 최대 12개를 선점해 종목별로 묶고 최대 3개 종목을 병렬 조회합니다. 대기 건수·시세 공급 지연·조회 실패에 따라 실제 감지 시점이 늦어질 수 있고 모든 장중 순간 돌파를 보장하지 않습니다. 지표 알림은 첫 검사에서 기준 상태를 기록한 뒤 새 조건 충족 때 발생합니다. 생성 시각보다 오래된 시세로는 알리지 않습니다. 알림마다 한 번 발생하고 종료하며, 다시 감시하려면 새 알림을 만듭니다. 계정당 활성 50개까지 지원합니다.
- **알림 수신**: 창을 닫아도 서버가 검사하고, 다음 로그인/접속 시 사이트의 **알림**에서 내역을 봅니다. 사이트가 열려 있으면 약 30초마다 내역을 갱신합니다. 이메일·OS 푸시·브라우저 종료 상태의 팝업 전송은 포함하지 않습니다. 시세 기준 시각과 알림 생성 시각을 구분합니다. 알림 생성·중지·삭제·읽음 처리는 소유자만 할 수 있고 내역 생성은 서버 전용입니다.
- **조건 검색**: 기존 거래대금 TOP100 범위를 유지합니다. 금액(미국 USD·한국 KRW), 등락률, ATR%, 업로드 RS, 미너비니 충족 개수, 거래량 배수, VCP와 관심종목 조건을 조합합니다. **상위 100종목 상세 조건 계산**을 누르면 최대 3개 병렬로 실제 일봉을 조회합니다. 중지할 수 있고 실패 건수·진행률을 표시합니다. 가격 목록과 확정 일봉 지표의 기준이 다름을 표시하고 자료 부족은 해당 숫자 조건에서 제외합니다. 업로드 RS와 TOP100 자체 백분위는 별도 열입니다. 조건은 이름을 붙여 최대 20개 저장합니다.
- **관심목록**: 최대 20개 목록, 같은 종목의 여러 목록 등록, 드래그·위아래 버튼 순서 변경, 색상 표시, 계정 메모를 지원합니다. 기존 그룹을 처음 열 때 새 목록으로 이관합니다. 목록 삭제는 전체 관심종목을 삭제하지 않습니다. CSV는 `market,symbol,name,group_name` 열을 사용하고 한국 종목은 `.KS`·`.KQ`를 포함합니다. 가져오기 전 목록을 확인하며 한 번에 200행·500KB까지 지원합니다. 내보내기는 따옴표·한글을 보존하고 스프레드시트 수식 실행을 방지합니다.

리플레이(6번)와 그리기 도구 추가 확장(7번)은 이번 요청에서 제외했습니다. 기존 여섯 그리기 도구·실행 취소·PNG 저장은 유지합니다.

### 알림 백엔드 재현

전용 `jins-trading` Supabase에 기존 `schema.sql` 적용 후 기존 설치를 업그레이드할 때 `supabase/features.sql`을 한 번 적용합니다. 새 설치도 같은 순서를 사용합니다. 기존 테이블·행을 삭제하지 않습니다. `trading_documents`, `trading_alerts`, `trading_notifications`에 RLS를 적용하고 소유자 정책·명시적 권한을 둡니다. 서버 RPC는 `service_role`만 실행하며, 작업자 토큰은 DB에서 생성해 Vault에 저장합니다. 토큰과 서비스 키를 브라우저·저장소에 넣지 않습니다.

`npm run prepare:alerts`로 차트/스크리너와 동일한 계산 소스를 Edge Function의 `shared`로 동기화합니다. `npm run build`는 두 소스가 일치하는지 검사합니다. `supabase/functions/trading-alert-worker`를 배포한 뒤 `supabase/alert-schedule.sql`을 적용합니다. 이 함수는 자체 토큰 인증을 수행하므로 게이트웨이 JWT 검사를 끄되 무토큰·잘못된 토큰은 401로 거절합니다. 활성 알림이 없으면 스케줄이 외부 HTTP 호출을 하지 않습니다. 사용자 알림 생성 전 스케줄·권한·실제 시세 기반 알림 처리 및 중복 방지를 검증했습니다.

## 한국장 진입·검색

차트 도구줄의 **미국장 / 한국장** 선택 또는 상단 **한국장** 버튼을 사용합니다. [한국장 바로 열기](https://jins-trading.vercel.app/?market=kr)도 지원하며, 명시한 시장이 계정의 이전 시장보다 우선합니다. 직접 시장을 바꾸면 주소도 갱신해 새로고침·공유 시 같은 시장으로 열립니다.

한국장에서는 한글 종목명·6자리 코드·`.KS/.KQ` 코드로 검색합니다. 현재 TOP100에 없는 종목도 서버의 한국 종목명 목록에서 찾고, 결과에 한글 이름·코드·코스피/코스닥 구분을 표시합니다. 검색 결과는 최대 20개이며 방향키·Enter·Esc를 지원하고 한글 조합 중 Enter는 검색으로 처리하지 않습니다. 종목명 원본은 2026-11-19 Naver Finance 코스피·코스닥 목록 4,331개이며 시세 지원/현재 거래 가능 여부와는 별개입니다. 없는 가격은 생성하지 않습니다. 갱신은 `python scripts/update-korean-stocks.py`를 사용합니다.

오른쪽 종목 목록과 스크리너의 **한국 시장**에서 코스피·코스닥·전체를 선택합니다. 거래대금·시총·등락률 정렬과 페이지 추가 조회는 선택한 시장 전체를 공급처에서 먼저 필터링한 결과입니다. 스크리너 상세 계산은 선택 시장의 거래대금 TOP100입니다. 전체 시장과 코스닥 TOP100 백분위의 모집단은 다를 수 있습니다.

분할 차트의 종목 연동을 끄면 각 차트에서도 같은 한국 종목 검색을 사용합니다. 개별 종목 선택은 미국·한국 시장별로 따로 기억하며, 기존 분할 설정은 종목을 올바른 시장으로 이관합니다. 코스닥은 `.KQ`, 코스피는 `.KS`로 정규화해 기존 알림·관심종목·도형 저장과 연결합니다. 차트·지표·분봉·원화 표시·코스피/코스닥 지수·지연 시세 안내는 유지합니다.

| 금·원유·원자재 | commodities | 금·은·WTI·브렌트·천연가스·구리 최근월물 선물 |

세계 지수·환율·원자재는 주요 자산 목록을 8개씩 실제 조회하며 개별 오류는 해당 행에 표시합니다. 해외 주식·ETF는 거래대금·등락·거래량 등 목록 정렬과 페이지 조회를 지원합니다. 해외 주식은 명시한 거래소의 보통주·현지 통화를 기준으로 하며 모든 국가의 모든 거래소를 포함하지 않습니다. 코드 변환이 불가능한 행은 제외하고 제외 개수를 표시합니다. ETF에 주식 시가총액 필터를 적용하지 않습니다.

검색은 선택한 시장의 이름·전체 코드를 사용합니다. 예: `7203.T`, `0700.HK`, `600519.SS`, `AZN.L`, `SAP.DE`, `RY.TO`, `2330.TW`. 중국 6자리 단독 코드는 상하이·선전을 임의 추정하지 않고 `.SS/.SZ` 또는 검색 결과를 요구합니다. 금·원유·환율·지수는 주요 목록의 한글 별칭과 코드로 찾습니다. 한국 ETF 한글명은 Naver Finance 목록 1,190개(2026-11-19)를 포함하며 제공처 목록/새 상장과 차이가 날 수 있습니다. `python scripts/update-korean-etfs.py`로 갱신합니다. 검색 장애 시 유효한 전체 코드는 직접 조회할 수 있습니다.

**가격과 단위**: 제공처 종목 ID·통화를 검증하고 시각을 표시합니다. GBP(파운드)와 GBp(펜스)를 바꾸어 표시하지 않습니다. 영국 주식 가격은 GBp일 수 있고 거래대금·시총은 제공처의 GBP 금액입니다. 지수는 포인트, 환율은 통화쌍의 표시통화, 금·은은 USD/트로이온스, 원유는 USD/배럴, 선물 거래량은 계약으로 표시합니다. 금·원유는 현물이 아니며 최근월물 교체로 연속 가격에 차이가 날 수 있습니다. 롤오버 역보정은 하지 않습니다. Yahoo 선물 타임스탬프의 현지 날짜와 TradingView 거래일 표기가 다를 수 있습니다.

**거래량**: 환율·지수의 거래량은 미제공으로 처리하며 임의 값이나 틱 수를 실제 체결량으로 대체하지 않습니다. 이때 거래량·매물대·거래량 조건은 계산할 수 없습니다. ETF·주식·선물은 제공처의 실제 원본 거래량을 사용합니다. 미너비니·VCP·업로드 RS는 주식용 수식을 그대로 적용한 참고값이며 타 자산에 대한 공식 평가 등급이 아닙니다.

**분봉**: 해외 시장·FX·원자재의 15분·30분·1시간봉은 원본 타임스탬프를 유지합니다. 4시간봉은 같은 세션의 연속 실제 1시간봉 최대 4개를 묶으며 점심 휴장·누락·유지보수 공백을 건너 합치지 않습니다. 짧은 세션/공백 앞뒤에는 4시간보다 짧은 봉이 생길 수 있고 TradingView의 봉 경계와 일치한다고 보장하지 않습니다. 제공처가 해당 자산/주기를 지원하지 않으면 오류로 알리고 일봉으로 대체하지 않습니다. 기존 미국·한국 집계와 지연 시세 안내는 유지합니다.

**비교·저장**: 종목 연동을 끄면 각 분할 차트에서 시장·자산을 따로 선택합니다. 주식·달러·금 등을 함께 배치하고 십자선/시간축을 연동할 수 있습니다. 거래소 현지 날짜를 사용해 호주처럼 UTC와 거래일이 다른 시장도 연결합니다. 시장별 종목·관심목록·메모·도형·CSV·알림을 계정에 저장하며 기존 미국/한국 문서는 보존합니다. 지수·FX의 거래량 알림은 지원하지 않고 가격·일봉 가격 지표 조건을 사용합니다. 알림 메시지에도 확인값 단위를 기록합니다.

기존 Supabase `features.sql` 설치 후 전용 프로젝트에 `supabase/global-markets.sql`을 한 번 적용합니다. 시장/코드 검증 범위만 늘리며 RLS 소유자 정책과 기존 행은 그대로 둡니다. Edge Function 공유 계산은 `npm run prepare:alerts` 후 배포합니다. 기존 사이트 내 알림 방식을 유지합니다.

## 사용자 보조지표

차트 상단의 **지표 추가**를 누르면 지표를 검색하고 추가할 수 있습니다.

- **이동평균선** 탭에서 SMA·EMA·WMA·RMA·VWMA·HMA, 1~500봉 기간, 시가·종가·고가·저가·평균 가격, 색상과 1~4px 두께를 선마다 선택합니다. 최대 8개이며 기본 20봉선은 검정색 `#111111` 3px입니다. 이전 설정도 숨김 여부와 사용자 지표를 보존해 새 형식으로 옮깁니다.
- 가격 차트 위: 여섯 이동평균, 볼린저 밴드, 누적 VWAP, 돈치안·켈트너 채널
- 아래 패널: RSI, MACD, ATR·ATR%, 스토캐스틱, Stochastic RSI, OBV, DMI·ADX, CCI, MFI, Williams %R, ROC, CMF
- **거래량·매물대** 탭에서 거래량과 매물대를 추가·제거하고 세부 설정을 바꿉니다. 거래량은 정확한 주수/K·M, 막대/선, SMA·EMA 평균선, 색상·두께를 선택합니다. 숫자는 차트 위·우측 축·커서와 연동됩니다.
- 매물대는 화면에 보이는 구간 또는 최근 N봉을 선택하며 구간 수, 너비, 색상, POC, 가치 영역 비율과 VAH·VAL을 설정합니다. 일봉 OHLCV 기반 추정치로, 더 낮은 주기 자료를 사용하는 TradingView 매물대와 동일한 결과를 보장하지 않습니다.
- 목록은 기본 거래량·RS·매물대와 사용자 지표를 합해 26개입니다. 동일 사용자 지표 여러 개 추가, 기간·색상·선 두께 변경, 숨김·삭제를 지원합니다 (사용자 지표 최대 12개).
- 지표와 가격 차트는 하나의 시간축과 크로스헤어를 공유합니다. 일·주·월봉을 변경하면 해당 봉의 실제 OHLCV로 다시 계산합니다.
- 지표 추가·편집 중 확대 구간을 유지하며, 커서를 움직이면 같은 봉의 지표 수치를 표시합니다.
- 설정은 버전을 포함해 저장합니다. 로그인하면 계정에 저장하고, 로그인 전에는 브라우저에 저장합니다. 계정별 문서와 브라우저 백업을 분리합니다.
- 기본 설정에서 1분 자동 갱신을 켤 수 있습니다. 화면이 보일 때만 조회하며 갱신 실패 시 마지막 차트를 유지합니다. 제공처 지연 시세가 실시간 시세로 바뀌는 것은 아닙니다.

차트와 RS 비교 데이터는 최대 10년의 일봉을 조회합니다. 신규 상장 또는 제공처 자료 부족으로 지표의 계산 기간을 채우지 못하면 `—`를 표시합니다. 미너비니·VCP 및 업로드 RS·미너비니는 선택 주기의 확정 봉 기준이며 ATR·VCP 카드는 일봉 기준입니다.

RSI는 Wilder 평균, EMA는 첫 기간의 SMA로 초기화하며 MACD 시그널도 EMA를 사용합니다. 볼린저 밴드는 모집단 표준편차, ATR은 14개 True Range로 초기화한 Wilder 평균입니다. 기간 누적 VWAP은 조회한 봉 전체의 typical price(HLC3)×거래량 누적값/누적 거래량으로, 장중 세션 VWAP과 다릅니다. OBV는 첫 봉을 0으로 두며 OBV·VWAP에서 거래량이 누락되면 그 봉 이후 누적 계산을 중단합니다.

## Supabase

전용 프로젝트: `jins-trading` · 서울 (`ap-northeast-2`).

`supabase/schema.sql`은 새 프로젝트에만 적용합니다. 사용자 데이터 테이블은 `trading_watchlist`, `trading_notes`이며 사용자 ID를 포함한 기본키와 RLS 소유자 정책으로 격리합니다. `anon`에는 읽기·쓰기 권한을 부여하지 않습니다. 클라이언트에는 publishable key만 사용하며 service role 키는 사용하지 않습니다.

`src/public-config.json`에 이 프로젝트의 URL과 공개 publishable key가 들어 있어 바로 빌드할 수 있습니다. 이 키는 브라우저에 노출하도록 설계된 공개 키이며 DB 권한은 RLS로 제한합니다. 비밀 키나 service role 키는 포함하지 않습니다. 아래 환경변수를 설정하면 공개 기본값을 덮어쓸 수 있습니다.

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

이메일·비밀번호 로그인을 사용합니다. 이메일 인증이 켜져 있으면 가입 확인 메일의 인증 후 사이트에서 로그인합니다. 필요 시 Supabase Authentication의 Site URL/Redirect URLs를 실제 배포 주소에 맞춥니다. 게스트 데이터는 로그인 시 자동 합치지 않으며 계정별 데이터를 분리합니다.

## 로그인 유지

로그인은 같은 브라우저의 기존 `jins-trading-auth-v1` 저장소를 계속 사용합니다. Supabase의 세션 영구 저장과 자동 토큰 갱신을 유지하며, 새로고침·브라우저 재시작 뒤 세션을 복원합니다. 복원 중에는 로그인 버튼 대신 **로그인 확인 중**을 표시하고 게스트 데이터에 쓰지 않습니다. 초기 조회 응답이 뒤늦게 도착해 새 로그인이나 명시적인 로그아웃을 덮어쓰지 않도록 처리합니다.

일시적인 연결 오류에는 현재 로그인 화면을 유지하고 다시 확인합니다. 네트워크 복구·탭 복귀·페이지 복원 시 SDK를 통해 세션을 읽고, 만료 토큰 갱신과 토큰 교체는 SDK가 관리합니다. 관심종목·메모의 초기 동기화가 실패하면 다시 연결됐을 때 재시도합니다. 새 토큰 저장소나 토큰 백업을 만들지 않으며 기존 RLS를 유지합니다.

로그아웃 버튼은 현재 브라우저의 세션만 종료합니다. 직접 로그아웃, 사이트 데이터 삭제, 시크릿 창 종료, 비밀번호 변경·세션 철회 등에는 다시 로그인해야 합니다. 브라우저가 사이트 저장을 막으면 유지할 수 없다는 안내를 표시합니다. 실제 브라우저 종료·재실행 검증은 도구 제한으로 하지 못했고, 자동 테스트는 설치된 SDK와 테스트 저장소·모의 Auth 응답으로 복원·토큰 갱신·로그아웃을 검증합니다.

## 시세 기준과 누락 방지

2026-11-20 신뢰성 점검 후 수정: 상단 가격·등락률과 지수 요약·자산 목록은 정규장 최신 시세 메타데이터를 사용하고, 차트 OHLC는 선택한 봉의 값으로 구분합니다. 등락률은 제공처의 전일 기준값(`previousClose`, 일중 가격·변동액 쌍 또는 정규장 등락률로 도출)을 사용합니다. 조회 범위 시작 가격인 `chartPreviousClose`와 뒤에서 두 번째 유효 봉을 전일 기준값으로 사용하지 않습니다. 기준값이 없으면 등락률은 미제공으로 표시합니다. 선물은 제공처의 전일 정산·종가 기준, FX는 제공처 거래일 기준입니다.

1분 자동 갱신은 기본으로 켜며, 이전 버전 설정도 한 번 켜짐으로 전환합니다. 이후 사용자가 끄면 그 선택을 저장합니다. 탭 복귀·네트워크 복구 시 다시 조회하며 숨겨진 탭에서는 반복 조회하지 않습니다. 시세의 경과시간과 서버 조회 경과시간을 구분하고, 제공처 거래시간 중 25분 이상 지난 가격 또는 2분 이상 갱신하지 않은 화면을 경고합니다. 데이터가 오래됐다고 임의 가격이나 봉으로 대체하지 않습니다.

주·월봉을 당일 정규장 마감만으로 확정하지 않습니다. 주식·ETF·지수 주봉은 주말부터, 밤에도 거래되는 FX·선물 주봉은 다음 주부터, 월봉은 다음 달부터 확정으로 취급합니다. 거래소 휴장일 달력이 없으므로 마지막 영업일을 추정해 조기에 확정하지 않는 보수적인 방식입니다. 분할 차트의 RS도 먼저 주·월봉으로 집계한 뒤 같은 판정을 적용합니다. 한국 일봉·분봉의 정규장 종료는 제공처가 15:00으로 반환해도 09:00 시작 기준 15:30으로 처리하며, 마감 직후에도 제공처 가격 기준 시각이 마감 이전이면 당일 봉의 확정을 기다립니다.

일부 Yahoo USD 통화쌍의 명시적인 동등 별칭(예: JPY=X → USDJPY=X)은 통화상품 타입·표시 통화를 검증한 뒤 허용합니다. 임의 종목 변경과 반대 통화쌍은 거부하며 자산 목록도 다른 Yahoo 호스트를 시도합니다. 두 호스트는 독립된 데이터 제공처가 아닙니다.

거래량은 Yahoo 원본 집계 그대로 사용합니다. 같은 완료 세션의 목록 거래량과 0.1% 넘게 다르면 출처 차이를 안내하며 다른 공급처 숫자로 일부 봉을 임의 보정하지 않습니다. 매물대는 계속 추정치이며 VCP도 후보 탐색 규칙입니다. 프리·애프터 데이터 연동은 이 수정에 포함하지 않습니다. 향후 차트에 별도 표시하더라도 정규장 가격·등락률·지표 계산 자료와 분리합니다.


차트 상단 **시세 기준 확인**에서 가격 제공 시각과 서버 조회 시각을 구분해 표시합니다 (화면 시각은 KST). 목록 제공처의 `update_mode`에서 읽은 지연 시간도 표시합니다. 2026-11-18 점검에서 미국 NASDAQ 종목은 15분, 한국 종목은 20분 지연으로 확인했습니다. 제공처·종목·시점에 따라 다를 수 있으며 Yahoo 차트의 지연 시간은 별도로 보장하지 않습니다. 두 공급처와 TradingView의 모든 설정에서 항상 동일한 체결가를 보장하는 구조는 아닙니다.

미국 일부 종목에서 Yahoo의 장기 일봉 배열은 최신 거래일을 `null`로 주고 메타데이터만 최신 가격을 주는 문제를 확인했습니다. 최신 거래일이 누락되거나 최근 봉과 메타데이터 가격이 다른 경우 같은 공급처의 `range=1d&interval=1d` 실제 OHLCV를 조회해 보완합니다. 가격 메타데이터만으로 봉을 만들어 넣지 않습니다. 보완 실패 시 유효한 과거 봉을 유지하고 최신 봉 누락·가격 불일치를 안내합니다. 종목 코드·통화 불일치는 거부하고, 누락/음수 거래량은 임의의 0으로 바꾸지 않습니다.

정규장 일봉을 사용하고 프리·애프터마켓을 섞지 않습니다. 장중 봉은 진행 중으로 표시합니다. 차트와 목록의 제공처, 거래일·최근 1분봉 시각·통화·가격 차이를 확인할 수 있습니다. 목록의 1분봉 시작 시각은 최종 체결 시각과 다릅니다. 상단 미국 지수는 ETF 가격 대신 실제 `^GSPC`·`^NDX`·`^DJI` 지수를 사용합니다. RS 기본 비교 ETF(SPY·QQQ)는 그대로 유지합니다.

일반 응답의 앱 CDN 캐시는 30초이며 오래된 응답을 추가로 제공하는 stale-while-revalidate를 제거했습니다. 새로고침/자동 갱신은 `fresh` 요청으로 앱 캐시를 우회합니다. 외부 제공처의 시세 지연까지 제거하지는 않습니다. 자동 갱신이 꺼져 있으면 화면에 표시하고, 가격 기준 시각은 접힌 상태에서도 확인할 수 있습니다.

캔들의 몸통과 꼬리는 양봉 빨강·음봉 파랑입니다. 거래량 막대/선과 숫자는 주가 방향에 관계없이 직전 봉의 거래량과 비교합니다. 일봉은 직전 거래일, 주봉·월봉은 직전 주·월봉 기준입니다. 거래량이 같거나 비교할 이전 자료가 없으면 회색이며, 이전 거래량이 0일 때 증가율을 무한대로 표시하지 않습니다.

실제 점검 기록: [PRICE_DATA_VERIFICATION.md](PRICE_DATA_VERIFICATION.md).

## 지표 정의와 데이터 범위

시세·일봉은 Yahoo Finance에서 조회하며 지연·누락·제공처 접근 제한이 발생할 수 있습니다. OHLC는 배당 보정 미적용입니다. 진행 중인 당일 봉은 바뀔 수 있습니다. 실시간 체결 데이터라고 표시하지 않습니다. 조회 실패 시 임의 시세를 생성하지 않습니다.

ATR%는 14일 Wilder ATR/종가×100입니다. 미너비니 기본 조건은 업로드 Pine 수식으로 맞췄습니다. 50·150·200봉선, 22봉 전 200봉선 비교, 기본 260봉 고저, 저가 대비 +25% 이상, 고가에서 25% 이내, 업로드 RS > 70입니다. Pine의 highest/lowest처럼 확보된 범위 내 고저를 사용하며 이동평균·RS에 필요한 봉이 부족하면 미확인으로 표시합니다.

RS 백분위는 TradingView Stock Screener의 해당 시장 거래대금 상위 100개 개별주식의 1년 수익률로 계산한 자체 지표입니다. 전체 시장 백분위, IBD 공식 RS Rating 및 독점 지표가 아닙니다. TOP100 밖의 종목은 RS 조건을 미확인으로 표시합니다. RS 선차트는 공통 거래일의 종목 종가/선택 지수 종가를 첫 공통 거래일 기준 100으로 환산합니다.

거래량 프로파일은 선택 구간 각 캔들의 거래량을 고저 범위에 균등 배분한 추정치이며 가격별 실제 체결량이 아닙니다. POC의 인접 구간을 거래량이 큰 쪽부터 포함해 설정 비율 이상을 차지하는 연속 가치 영역을 구합니다. 구간 단위로 계산하므로 실제 포함 비율은 설정값보다 커질 수 있습니다. VCP는 고정 세 구간의 가격 변동폭과 평균 거래량 감소를 비교하는 탐색 보조 지표이며 패턴을 확정하지 않습니다. 업로드 RS·미너비니는 선택 봉 주기를 사용하고 ATR·VCP 카드는 일봉 기준입니다.

공식 문서 확인 내역과 지원 범위: [INDICATOR_SOURCES.md](INDICATOR_SOURCES.md). 전체 TradingView 지표·Pine Script를 실행하거나 복제하는 제품은 아닙니다.

## 배포

GitHub 저장소명과 Vercel 프로젝트명은 `jins-trading`입니다. 운영 주소 `https://jins-trading.vercel.app` 할당 및 공개 페이지 HTTP 200 응답을 확인했습니다. GitHub `main` 브랜치에 변경을 올리면 Vercel에서 자동 배포합니다. 다른 프로젝트의 환경변수나 DB를 재사용하지 않습니다.

Vercel: Vite / build `npm run build` / output `dist` / Node.js 24. 새 Supabase 연결은 공개 기본 설정에 포함되어 있습니다. 별도 프로젝트로 변경할 때만 위 환경변수를 등록합니다. 개인용 Supabase 프로젝트의 무료 DB 한도는 500MB이며 이 앱은 시세 전체를 DB에 복제하지 않고 관심종목·메모만 저장합니다.

## 차트 라이선스

차트는 TradingView의 Apache-2.0 라이선스 [Lightweight Charts](https://github.com/tradingview/lightweight-charts)를 사용합니다. 라이브러리 기본 TradingView attribution을 유지하고 차트 아래에도 제공자 링크를 표시합니다. 이 사이트는 TradingView 공식 제품이 아닙니다.

매물대 기본 색상은 연한 회색입니다. 이전 기본 하늘색 설정은 회색으로 이관하고 직접 지정한 다른 색상은 유지합니다.
